## 💫 About Me

Full-Stack Developer building responsive, production-ready web applications.

I work with the **MERN stack, Next.js and Nest.js** to ship dashboards, e-commerce
platforms and Web3 apps with clean architecture and solid performance.

### 📌 What I do

- End-to-end product development: frontend, backend, database, deployment
- REST APIs and modular backends with Node.js / Nest.js / Express
- Responsive, animated UIs with React, Next.js and Tailwind CSS
- Auth (JWT, OAuth2), Stripe payments and third-party integrations
- Web3 features — wallet connect, minting flows with wagmi & viem
- Deployment on Vercel and Docker-based setups

**🧠 How I work** — ship first, keep it simple until it needs to scale, and never commit secrets.
